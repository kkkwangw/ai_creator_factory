# 安全规则

- `.env`、密码和 API Key 只存在对应机器本地，永不进入日志、Markdown、部署清单或远程同步。
- 微信读书只允许五个公开资料接口；标准化时移除个人标识，原始响应不长期保存。
- 所有上传必须来自显式部署清单；禁止递归上传、通配符上传和删除式同步。
- `.env`、`.local/tools.toml`、模型、缓存和大型媒体不得自动上传。
- ID 仅允许小写字母、数字和连字符；相对路径拒绝绝对路径、`..` 和符号链接逃逸。
- SSH 使用用户名密码和 TOFU。新 endpoint 自动记录；已知 endpoint 指纹变化时阻塞。
- 远程项目根必须与 `project_id` marker 匹配，禁止自动回退到 `/root` 等临时目录。
- ComfyUI 只允许监听 `127.0.0.1`；检测到 0.0.0.0 或公网端口时立即阻塞。
- 远程不运行 Codex、LLM 或可自行改写任务的 Agent。
- 删除只按保留策略和精确路径执行；禁止模糊 kill、递归删除广泛目录或覆盖未知远程 Markdown。
