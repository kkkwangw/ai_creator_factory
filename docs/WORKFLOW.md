# Book Video Workflow

| Gate | 输入 | 主要输出 | 不可关闭的阻塞 |
| --- | --- | --- | --- |
| 1 书籍资料 | 书名及可选作者/ISBN/方向 | 脱敏书籍记录、封面来源 | 版本歧义、Skill升级、鉴权失败 |
| 2 文案分镜 | 书籍证据、角色和模板 | 48--55秒文案、10镜头、提示词、发布文案 | 事实冲突、长度不合格 |
| 3 MiMo语音 | 旁白文字、冰糖音色 | WAV、ffprobe、Whisper对齐 | 关键字错误、时长异常、不可解码 |
| 4 人物与关键帧 | 已批准角色包、候选图片插件 | 10张关键帧和工作流证据 | 角色包无效、模型未批准 |
| 5 视频与口型 | 关键帧、WAV片段 | 10个约5秒片段、2个口型结果 | 技术失败、预算耗尽 |
| 6 合成交付 | 有效片段、字幕、BGM、书籍封面 | MP4、发布封面、发布文案、清单 | 编码/哈希/依赖验证失败 |

## 失效矩阵

Gate N 的真实输入或产物变化时，N 到 6 全部失效：

```text
1 -> 1,2,3,4,5,6
2 ->   2,3,4,5,6
3 ->     3,4,5,6
4 ->       4,5,6
5 ->         5,6
6 ->           6
```

返工创建新 `run_id`，任务和提示变更创建新 `task_id`/`prompt_id`。旧 ID 和结果目录不可覆盖。

## 时间线

- MiMo WAV 目标 48--55 秒，文案超时时重写并重新生成，不明显变速。
- 1、10为约5秒人物口播；2--9为氛围镜头。
- Wan统一生成121帧/24fps（约5.04秒），剪辑只在句界取3--5秒。
- 原始字幕文字来自文案；Whisper只负责时间对齐和回转写证据。

## 完成定义

`ready_for_download` 必须由 Runner重新验证 Gate 1--6的真实输入、产物和技术证据后推导，不能
读取某个 Gate先前保存的 `done` 结论。当前 `verify_delivery.py` 只覆盖 Gate 6的部分交付规格，
因此只返回 `delivery_artifacts_verified`，不会冒充流程终态。

完整 Runner实现后，`ready_for_download` 仍只代表技术质检通过，不代表人工审美验收。用户观看
发现问题后，本地 Codex检查真实产物，定位最早错误 Gate并重做该 Gate到 Gate 6。
