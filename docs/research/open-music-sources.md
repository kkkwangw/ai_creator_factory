# 书籍推荐视频的开放/授权音乐来源

> 核验日期：2026-08-04。本文只引用平台、许可方、工具项目或版权机关的官方页面；它是产品风险控制建议，不是法律意见。平台条款会变化，实际使用时仍须核对具体曲目页面和当日条款。

## 结论与安全短名单

“免费”“royalty-free”不等于无版权，也不等于可在任何平台、任何商业场景使用。对会公开发布、可能变现或推广书籍/账号的视频，首版应按潜在商业使用处理。

| 优先级 | 来源 | 建议用途 | 关键条件 |
| --- | --- | --- | --- |
| 1 | [Incompetech](https://incompetech.com/music/royalty-free/licenses/) | 多平台公开视频 | 只用明确标注 CC BY 4.0 的曲目并完整署名；不想署名时购买 Standard License。其音乐已预登记 YouTube Content ID，缺署名可能触发 claim。 |
| 1 | [Mixkit Stock Music](https://mixkit.co/license/#musicFree) | 网页、社交平台、播客和网络广告 | 可用于商业项目；不得做音乐再混/纯音乐轨、宣称为己有或注册权利管理服务；不适用于 CD/DVD、游戏、电视或广播。 |
| 1（YouTube 专用） | [YouTube Audio Library](https://support.google.com/youtube/answer/3376882?hl=en) | YouTube 视频 | 可变现；逐曲遵守“需署名/无需署名”标记。YouTube 的 copyright-safe/Content ID 保证明确围绕 YouTube，不要自动跨平台复用。 |
| 2 | [Pixabay Music](https://pixabay.com/music/) | 多平台创作视频 | 无需署名、可用于商业视频，但音乐必须嵌入更大的创作作品，禁止 standalone 分发；优先选无 Content ID 盾牌的曲目并保存下载凭证。 |

首版不应默认开放 [Free Music Archive（FMA）](https://freemusicarchive.org/License_Guide)。艺术家自行选择许可，FMA 不持有作品版权，也不能替用户发放超出曲目许可的授权；其公共领域状态也仅为“尽其所知”，不是权威认定。若启用，只允许人工复核后的 CC0 或 CC BY 曲目。

[ccMixter](https://ccmixter.org/how-to-attribute-ccmixter-tracks) 同样是逐曲 CC 许可的混合库，其[官方条款](https://ccmixter.org/terms)不提供不侵权保证，也没有平台级 Content ID 保障，首版应转人工复核。[FreePD](https://freepd.com/) 官网现已标注永久关闭（2008-2025），不再作为当前稳定来源。

## 许可和平台差异

| 来源/许可 | 商业视频与署名 | 再分发/改编 | Content ID 与其他 caveat |
| --- | --- | --- | --- |
| [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) | 可复制、修改、传播和表演，包括商业用途，通常无署名条件。 | 许可本身允许分发和改编。 | CC0 页面不提供权属保证；仍要留存曲目来源和权利人的 CC0 声明。 |
| [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | 可商用，但必须合理署名、链接许可并标注是否修改。 | 可分享和改编；不得施加阻止他人行使许可权利的额外法律或技术限制。 | 许可不作保证，隐私、人格、商标等其他权利可能仍适用。不要把非独占开放音乐注册为自己的 Content ID 参考资产。 |
| CC BY-SA | 可商用并须署名。 | 改编后需以相同许可共享；视频同步后的交付义务更复杂。 | 首版转人工复核，不自动准入。 |
| CC BY-NC 系列 | 仅非商业用途；[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)把许可范围限定为非商业目的。 | 依具体许可而定。 | 书籍推广、品牌账号、广告、赞助或变现边界不稳定，首版一律拒绝。 |
| CC BY-ND 系列 | 即便允许再分发，也不允许发布改编材料。 | [FMA 官方指南](https://freemusicarchive.org/License_Guide)明确把音乐与移动画面同步视为衍生作品，因此不适合作为视频配乐。 | 首版一律拒绝。 |
| Pixabay Content License | [许可摘要](https://pixabay.com/service/license-summary/)允许免费使用、无需署名和修改；[官方 FAQ](https://pixabay.com/service/faq/)明确允许商业视频。[完整条款](https://pixabay.com/service/terms/)仅把 2019-01-09 前发布的旧内容归为 CC0，不能把当前全站音乐称为 CC0。 | 不得 standalone 销售或分发；音乐应只是更大创作作品的一部分。 | 贡献者或发行商可能注册 Content ID，合法使用仍可能收到 claim；盾牌曲目可下载 license certificate。第三方知识产权仍由使用者核查。 |
| Mixkit Music Free License | 商业和非商业的网络/社交视频均可免费使用。 | 可嵌入视频并公开发布，但禁止音乐再混、纯音乐成品、转售/库存式再分发和宣称为己有。 | 禁止注册权利管理服务；官方许可页说明 YouTube claim 可提交给 Mixkit 协助处理，但不等于不会触发 claim。 |
| YouTube Audio Library | YouTube Partner Program 中可变现；CC 曲目必须按说明署名，标准 Audio Library 曲目可筛选“无需署名”。 | 官方帮助页的保证围绕 YouTube 视频，不应推定站外授权范围。 | YouTube 称从 Audio Library 下载的内容不会被权利人通过 Content ID claim；该保证不覆盖其他曲库或站外问题。 |
| Incompetech | 免费方案为 CC BY 4.0，允许商业视频但必须显著署名；无法署名时购买 Standard License。 | 可按 CC BY 4.0 剪辑、改编和分享，但录音仍受版权保护，不是 public domain；不要推定可作为素材库独立转售。 | [官方 Content ID 说明](https://incompetech.com/music/royalty-free/youtube-contentid.html)称曲目已预登记以阻止虚假登记；缺署名可能触发 claim，应先补署名再争议。另见[官方 FAQ](https://incompetech.com/music/royalty-free/faq.html)。 |
| FMA | 每首曲目许可不同；CC BY 可商用且须署名，NC 不可用于商业/推广。 | ND 不可同步视频；SA 需履行相同方式共享；CC0 可用但仍需核验声明人和录音来源。 | 用户上传且许可由艺术家选择。平台不拥有版权，也无平台级 Content ID 保证，因此不作为首版自动来源。 |

## 从用户视频提取音频

技术上可以提取。[FFmpeg 官方文档](https://ffmpeg.org/ffmpeg.html#Stream-selection)说明 `-map` 可选择音频流，`-vn` 可跳过视频流；例如在兼容容器/编码下可执行 `ffmpeg -i input.mp4 -vn -c:a copy output.m4a`，否则需转码。

技术可行不代表有权公开复用。文件由用户上传，只证明用户能提供该文件，不证明用户拥有其中音乐的复制、改编、同步和公开传播权限。[美国版权局的版权说明](https://www.copyright.gov/what-is-copyright/)将复制、制作衍生作品和向公众分发列为版权人的专有权，并指出版权人可授权他人行使这些权利；具体例外和司法辖区需另行判断。

例如，[YouTube 服务条款](https://www.youtube.com/t/terms?hl=zh-cn&override_hl=1)并不因为用户能观看或提交视频就普遍授权下载、复制、分发或站外独立使用；[YouTube 的许可类型说明](https://support.google.com/youtube/answer/2797468?hl=en)也区分默认 Standard YouTube License 与上传者明确选择的 CC BY。

因此首版应区分两个动作：

- **允许技术提取**：仅在本地工作流中从用户文件拆出音轨，用于经授权的编辑或分析。
- **允许随成片发布**：仅当用户确认其为权利人，或提供覆盖视频配乐/同步、商业用途（如适用）和目标发布平台的许可。来源不明、来自影视/短视频/流媒体录屏或仅声称“网上免费下载”的音频，默认不进入发布成片。

该确认不能替代专业法律判断；遇到争议、权属冲突或例外主张时停止自动发布。

## 推荐的首版政策

1. **来源 allowlist**：默认只接入 Incompetech CC BY 4.0、Mixkit Music Free、YouTube Audio Library（仅 YouTube 输出）和 Pixabay Music；FMA、ccMixter 及其他用户上传曲库进入人工复核。
2. **许可 allowlist**：自动接受证据完整的 CC0、CC BY 4.0 和上述平台专用许可；拒绝 NC、ND、未知许可，SA 转人工复核。
3. **逐曲留证**：下载时保存曲名、作者、原始 URL、许可名称/版本、下载日期、许可页快照或文本、署名文案、文件哈希；Pixabay 额外保存 Content ID 标记和可用的 license certificate。
4. **署名默认开启**：即使平台不强制，也保留曲名/作者/来源；CC BY 必须包含作者、作品、许可链接和修改说明。描述区长度不足时阻止发布，不静默删减署名。
5. **禁止权利圈占**：不上传或注册原曲、提取音轨或含库音乐的成片到 Content ID/其他权利管理服务，不把库音乐作为可下载的独立音轨交付。[YouTube 的 Content ID 资格规则](https://support.google.com/youtube/answer/1311402?hl=en)要求提交者控制独占权，并明确把非独占授权内容列为通常不合格。
6. **发布前再校验**：许可范围必须覆盖目标平台、商业属性和媒介；同一视频跨平台发布时按最严格平台重新检查，不能沿用 YouTube 专用判断。
7. **claim 处置**：自动暂停变现/发布队列，凭留存证据走平台 dispute；不反复重传规避检测。若来源或许可无法复核，替换音乐。
8. **用户素材声明**：上传界面要求用户确认拥有或已获必要授权，并记录授权范围；声明缺失只允许本地提取/预览，不允许公开发布。

这套政策优先降低下架、静音、收入转移和权利争议风险，而不是追求最大曲库覆盖率。
